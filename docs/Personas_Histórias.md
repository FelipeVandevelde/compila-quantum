# User Stories **Programador**

| História | User Story | Critérios de Aceitação |
| ----- | ----- | ----- |
| **US01** | Como programador que está começando a estudar Computação Quântica, quero encontrar uma sequência organizada dos tópicos que preciso estudar, para que eu saiba por onde começar e consiga compreender a área de forma progressiva. | A plataforma deve apresentar uma sequência definida de tópicos destinada ao início do aprendizado. Deve ser possível identificar claramente qual é o ponto inicial da sequência e a continuidade dos tópicos seguintes. |
| **US02** | Como programador que está começando a estudar Computação Quântica, quero encontrar materiais didáticos relacionados aos conteúdos que estou estudando, para que eu consiga aprofundar minha compreensão desses conteúdos. | A plataforma deve disponibilizar materiais didáticos relacionados a cada conteúdo abordado na plataforma. O usuário deve conseguir acessar o material relacionado ao tópico que está estudando. |
| **US03** | Como programador que está aprendendo Computação Quântica, quero aplicar os conceitos estudados na construção e execução de circuitos quânticos, para que eu desenvolva experiência prática na área. | A plataforma deve permitir que o usuário construa os circuitos utilizando os recursos disponibilizados no ambiente de experimentação. O usuário deve conseguir executar ou simular o circuito construído. O usuário deve conseguir alterar o circuito e realizar uma nova execução ou simulação. |
| **US04** | Como programador que está começando a estudar Computação Quântica, quero encontrar um meio de buscar ajuda quando tiver dúvidas sobre os conteúdos estudados, para que eu consiga continuar meu aprendizado quando encontrar dificuldades.  | A plataforma deve indicar ao usuário onde ele pode buscar ajuda para dúvidas relacionadas ao aprendizado. Ao selecionar esse meio de apoio, o usuário deve conseguir acessar o canal ou recurso definido para esclarecimento de dúvidas. |

# User Stories **Estudante iniciante**

| História | User Story | Critérios de Aceitação |
| ----- | ----- | ----- |
| **US11** | Como estudante iniciante em Computação Quântica, quero aprender os conceitos de forma clara e aplicá-los em atividades práticas, para que eu consiga compreender conteúdos abstratos e consolidar meu aprendizado. | Os conteúdos teóricos devem explicar de forma clara os conceitos e termos técnicos, considerando o nível iniciante do estudante. A plataforma deve disponibilizar atividades práticas relacionadas aos conteúdos estudados. A atividade prática deve exigir a aplicação do conceito apresentado no conteúdo correspondente. |
| **US12** | Como estudante iniciante em Computação Quântica, quero criar e modificar circuitos quânticos e executar suas simulações, para que eu consiga observar na prática como as alterações realizadas influenciam os resultados. | A plataforma deve permitir que o estudante crie, modifique e execute um circuito quântico no ambiente de experimentação. | **US13** | Como estudante iniciante em Computação Quântica, quero visualizar de forma gráfica como a execução de um circuito altera o estado dos elementos quânticos envolvidos, para que eu consiga compreender melhor o efeito das operações realizadas sem depender apenas de explicações abstratas. | A plataforma deve apresentar uma representação visual do estado resultante dos qubits, quando esse tipo de representação for aplicável. Ao modificar o circuito e realizar uma nova execução, a representação visual deve ser atualizada de acordo com o novo estado obtido. A plataforma pode utilizar representações visuais apropriadas, desde que estejam associadas ao resultado da simulação. |

# User Stories **Entusiasta**

| História | User Story | Critérios de Aceitação |
| ----- | ----- | ----- |
| **US14** | Como pessoa que gosta de desafios progressivos, quero acompanhar meu avanço à medida que concluo atividades e desafios, para que eu consiga perceber meu progresso e me manter motivado a continuar aprendendo. | A plataforma deve indicar quais atividades ou desafios foram concluídos pelo usuário. O usuário deve conseguir visualizar seu progresso nas atividades ou desafios realizados. O progresso apresentado deve ser atualizado após a conclusão de uma nova atividade ou desafio. |
| **US15** | Como pessoa que gosta de superar desafios, quero tentar novamente um desafio que não consegui concluir, para que eu possa testar novas estratégias e continuar evoluindo na resolução dos problemas. | O usuário deve poder realizar uma nova tentativa em desafios que não foram concluídos. Ao iniciar uma nova tentativa, o desafio deve ser reiniciado em seu estado inicial. O usuário deve conseguir repetir o desafio quantas vezes forem necessárias. |
| **US16** | Como pessoa que gosta de desafios progressivos, quero encontrar desafios com níveis crescentes de dificuldade, para que eu possa continuar testando minhas habilidades e avançando para problemas mais difíceis. | A plataforma deve organizar os desafios de forma progressiva, permitindo que o usuário avance para problemas mais difíceis. O usuário deve conseguir identificar quais desafios correspondem ao seu nível atual e quais representam etapas posteriores de dificuldade. |
| **US17** | Como curioso, quero ter um ambiente de experimentação livre, no estilo Sandbox, para que eu possa testar interações quânticas, modificar elementos e observar seus efeitos sem depender de objetivos ou etapas predefinidas. | A plataforma deve disponibilizar um modo livre sem requisitos de conclusão. O usuário deve poder manipular livremente os elementos interativos e visualizar os efeitos imediatos. Deve haver uma opção para resetar instantaneamente o ambiente para o estado inicial com um único clique. |
